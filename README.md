## Project Overview

This project is a multiplayer Bomberman-style game developed in Java. It was created as part of the **Software Technology** course at **ELTE IK**. Development was based on the requirements specified in the provided documentation: `bomberman.pdf`.

## Running the Game

Download the release and run the following command:

```bash
java -jar bomberman.jar
```

## Key Bindings

Key bindings can be viewed and customized from the in-game settings menu.
